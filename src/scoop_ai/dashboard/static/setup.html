Signing in to

Scoop AI asks the camera for its own stream address, so you do not need to know the vendor’s RTSP path.
Include the username, password and the vendor stream path. Common paths are /stream1, /Streaming/Channels/101 and /cam/realmonitor?channel=1&subtype=0. Reserve the camera address in the router before unattended use.
Stored in Windows Credential Manager — never in configuration files or the cloud. Network discovery never overwrites a saved credential.
